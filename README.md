# Sivagiftese_e-commerce-_anoth
This e-commerce website was built for a business to offer customizable products across various categories. It provides a smooth user experience, easy navigation, and direct WhatsApp Business contact for specific needs—everything you need in one place


This is a user-friendly and responsive e-commerce website designed to provide a seamless shopping experience. Users can easily navigate through various sections such as New Arrivals, Featured Products, and more via a dropdown product menu. Direct integration with WhatsApp Business allows customers to inquire about specific products instantly.

Features
✅ Clean and simple UI/UX for easy navigation

✅ Dropdown-based product menu for category access

✅ WhatsApp Business integration for direct customer support

✅ Product listings: New Arrivals, Featured Products, and more

✅ Fully responsive design for desktop and mobile devices

Technologies Used
Frontend:

HTML5

CSS3

JavaScript (for interactive elements and menu toggling)

Backend / CMS Integration:

WordPress (for content and product management)

PHP (server-side scripting)

XAMPP (local development server stack)

WooCommerce Plugin (for e-commerce functionality)

Setup Instructions
Clone the repository

Set up XAMPP and place the project in the htdocs directory

Create a database via phpMyAdmin and import the WordPress SQL file

Configure wp-config.php with your database credentials

Activate the custom theme from the WordPress dashboard

Install and configure the WooCommerce plugin
